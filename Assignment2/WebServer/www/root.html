You can make the following GET requests

  • /file/sample.html -- returns the content of the file sample.html
  • /json -- returns a json of the /random request
  • /random -- returns index.html
  • /convert?type=0&text=abcdefghijKLMop -- converts text to uppercase
  • /convert?type=1&text=hello world leet -- converts text to leetspeak
  • /count?char=a&text=thefoxjumpedovertheredappletreeandateabird -- counts number of a specific character
